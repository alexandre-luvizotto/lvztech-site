## 🎯 Objetivo

Apresentar a LVZTECH como empresa de tecnologia de Curitiba e levar o visitante a entrar em contato: criação de sites, sistemas sob medida e SaaS para negócios locais.

## ✨ Funcionalidades

- Visual premium em **branco e azul fosco**, com animações.
- **Portfólio** com os produtos próprios (AM CELL OS, VYKRON).
- **Serviços** com preços sob consulta e chamadas diretas para o WhatsApp.
- **Depoimentos** de clientes.
- Seção de **apoio aos estudos** de faculdade (materiais e dicas).
- Layout **responsivo** para celular e desktop.

## 🏗️ Infraestrutura

- Domínio `lvztech.com.br` com DNS gerenciado na **Hostinger**.
- Subdomínio `amcell.lvztech.com.br` dedicado ao sistema [AM CELL OS](https://github.com/alexandre-luvizotto/amcell-os).
- E-mail do domínio na própria Hostinger.
